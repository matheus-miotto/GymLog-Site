# GymLog — Site Institucional

Site institucional do GymLog, construído com [Astro](https://astro.build).

🔗 **Site publicado**: https://matheus-miotto.github.io/GymLog-Site/ (deploy automático a cada push em `main`)

**v1.0.0 — projeto funcionalmente concluído.** Todas as páginas institucionais (Home, Política de Privacidade, Termos de Uso, Suporte) têm conteúdo definitivo, com SEO, sitemap, `robots.txt`, página 404 e acessibilidade revisados. O site está em **modo de manutenção**: novas alterações devem refletir mudanças reais no aplicativo GymLog (novas funcionalidades, publicação nas lojas, screenshots oficiais, domínio próprio), não novas funcionalidades do site em si — ver [ROADMAP.md](./docs/ROADMAP.md).

Documentação completa em [docs/README.md](./docs/README.md), incluindo objetivo do projeto, stack, estrutura de pastas, convenções, publicação e instruções para executar localmente.
